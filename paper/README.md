## `cresta_real.tex` is generated, not written

Edit the prose in `src/generate_paper.py` and regenerate:

```
PYTHONPATH=src python src/generate_paper.py
```

Every numeric result is read from a pipeline artefact — `models/registry.json`,
`reports/phase3/`, `reports/phase6/`, `reports/phase7/`. **No figure is typed
in.** That constraint exists because the three superseded drafts all carry
hand-transcribed numbers, and the pipeline was rerun three times after they
were written — twice because a defect was found. A paper that cannot be
regenerated goes stale silently.

## Why the superseded drafts are kept

They are the record of the earlier work, and the models that produced them are
preserved in `models/deprecated_synthetic/` for the same reason. They are not
citable as results: the ESG effect in the synthetic generator was **injected**
at γ = −4.0, so any ESG finding in those drafts is an artefact of the
generator, not evidence.

## Compiling

No LaTeX toolchain is installed in this environment, so `cresta_real.tex` has
**not been compiled here** — it is syntax-checked (balanced environments,
escaped data-derived strings) but not rendered. It targets `IEEEtran`
(conference):

```
pdflatex cresta_real.tex && pdflatex cresta_real.tex
```
